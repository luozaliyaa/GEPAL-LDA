# GEPAL-LDA

GEPAL-LDA predicts lncRNA-drug associations by combining graph neural network representations with a prefix-augmented large language model. The workflow integrates lncRNA and drug features, constructs an lncRNA-drug association graph, maps graph embeddings into LLM prefix tokens, and fine-tunes the language model with LoRA for binary association inference.

## Main Data Used

The current main experiment uses the RF-balanced D-lnc feature dataset:

```text
data/D-lnc_with_features/
```

Important files include:

- `lnc_features.txt`: lncRNA feature matrix.
- `drug_features.txt`: drug feature matrix.
- `adj_matrix.txt`: lncRNA-drug adjacency matrix used for graph construction.
- `lnc_drug_dataset_rf_balanced.json`: balanced positive and reliable negative samples.
- `10fold_rf/`: 10-fold train/validation/test splits.
- `rf_negative_sampling_summary.json`: random forest negative sampling summary.

## Environment

Create a Python environment and install dependencies:

```bash
pip install -r requirements.txt
```

PyTorch and PyTorch Geometric should be installed with versions matching the local CUDA driver. If the default `pip install` does not provide a compatible build, follow the official PyTorch and PyG installation pages for the correct CUDA wheel.

## Base Model

The LLM backbone is not included in this repository. Before training or inference, provide a local path or Hugging Face model identifier for the base model, for example:

```text
/path/to/MMed-Llama-3-8B
```

In the current code, `my_finetune.py` expects `base_model` to be passed to `train()`, and `my_inference.py` should be configured with the same base model path before running inference.

## Negative Sampling

Reliable negative lncRNA-drug pairs can be generated with:

```bash
python rf_negative_sampler.py
```

The default configuration writes outputs under:

```text
data/D-lnc_with_features/
```

The current summary reports 2224 lncRNAs, 1225 drugs, 32706 positive pairs, and 32706 selected reliable negative pairs.

## Data Splitting

The 10-fold RF-balanced splits are generated by:

```bash
python split.py
```

The script writes fold-specific train, validation, and test JSON files to:

```text
data/D-lnc_with_features/10fold_rf/
```

## Training and Inference

The main training and evaluation logic is in:

- `my_finetune.py`: LoRA fine-tuning with graph-prefix augmentation.
- `my_inference.py`: fold-level inference and metric calculation.
- `main.py`: example script for running training and inference.

Before running `main.py`, make sure:

1. The base model path is configured.
2. The intended fold range is selected.
3. The required data split exists under `data/D-lnc_with_features/10fold_rf/`.
4. Output directories such as `train_res_rf/` and `metrics_rf/` are available or can be created.

## Evaluation Metrics

The inference script reports:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC

ROC and PR curves are saved under the configured metrics output directory.

## Reproducibility Notes

- Random forest negative sampling uses random seed 42.
- The 10-fold split script uses random seed 42.
- The base LLM weights are not included and must be downloaded or provided separately.
- Large generated files, trained checkpoints, and full metric outputs should be archived separately, for example on Zenodo or another persistent repository, before manuscript submission.
